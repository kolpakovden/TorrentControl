## История изменений TorrentControl

Здесь отражаются **опубликованные версии**. До первого выпуска дата и состав релиза не фиксируются как состоявшиеся.

## [Unreleased] - кандидат на первый публичный выпуск (`v1.0.0`)

### Возможности, планируемые для выпуска

- Мониторинг состояния µTorrent на D:
- Автоматическое добавление новых релизов фильмов из форума RuTracker 252 после отдельного включения.
- Учёт свободного места на D: и защита от повторной передачи торрентов в клиент.
- Персональные `.torrent` RuTracker для начисления статистики отдачи, локальное хранение данных входа через DPAPI.
- Проверка подключения и TLS 1.3 на Windows 10 с BouncyCastle.Cryptography 2.7.0.
- Контролируемая перепривязка старых раздач с публичного трекера на персональный без повторной загрузки.
- Публичный фид и кэш метаданных, обновляемые GitHub Actions.
- Документация для установки, диагностики и лицензирования.

### Не входит в первый релиз

- Автоматическое удаление раздач и файлов.
- Dry Run очистки из отдельной экспериментальной ветки (планируется после первого релиза).
