## Установка TorrentControl

Эта инструкция предназначена для **первой установки** планируемого публичного выпуска с поддержкой персональных `.torrent` RuTracker. Для обновления старой установки необходимо соблюдать отдельную проверенную процедуру - обычная распаковка поверх работающей программы небезопасна.

## Подготовка

1. Windows 10, Windows PowerShell 5.1, запущенный **µTorrent 2.2.1** с WebUI (проверено на build 25534).
2. В µTorrent включите WebUI, задайте логин и пароль. В локальной конфигурации обычно используется `http://127.0.0.1:9090`, но адрес и порт должны соответствовать настройкам вашего клиента.
3. Для автозагрузки подготовьте диск **D:** и папку `D:\Фильмы`. Другие диски автозагрузкой не используются.
4. Скачайте ZIP именно из официального GitHub Release и распакуйте программу, например, в `C:\TorrentMonitor`. Сохраняйте все `.ps1`, `.cmd`, `.cs` и папку **`lib`** вместе. Убедитесь, что это постоянная папка, а не временный каталог загрузок.

## Первая настройка

1. Запустите **`1-Setup.cmd`** под тем пользователем Windows, который будет постоянно выполнять монитор. Введите адрес µTorrent WebUI и его учётные данные. Настройки и пароль сохраняются локально (пароль - через Windows DPAPI).
2. Проверьте **`2-Run-once.cmd`** и отчёт `report.html`. При успешной настройке создаётся задача **`TorrentMonitor-DF`** с интервалом около 15 минут. Для запуска должен оставаться выполненным вход того же пользователя в Windows. Заблокированный экран или отключённая RDP-сессия допустимы; выход из учётной записи - нет.
3. Запустите **`9-RuTracker-login.cmd`** для входа в RuTracker, затем **`10-RuTracker-check.cmd`** для проверки персонального `.torrent`.
4. Если RuTracker с ПК недоступен, запустите **`15-RuTracker-connection.cmd`** для проверки доступных маршрутов. Его настройки прокси относятся только к запросам TorrentControl к RuTracker. Подробнее - [RUTRACKER.md](RUTRACKER.md).
5. Когда проверка RuTracker завершилась успешно, при необходимости включите **`6-Enable-autoload.cmd`**. Программа запомнит уже известные темы и станет добавлять **только новые** подходящие публикации.

**Важно:** `6-Enable-autoload.cmd` - необязательный шаг. Мониторинг и отчёты работают без автозагрузки. `7-Disable-autoload.cmd` выключает будущие добавления, но не останавливает уже существующие торренты.

## Проверка работы

В PowerShell можно **только прочитать** состояние задачи:

```powershell
Get-ScheduledTaskInfo -TaskName 'TorrentMonitor-DF' | Format-List LastRunTime,LastTaskResult,NextRunTime
Get-Content 'C:\TorrentMonitor\monitor.log' -Tail 20 -Encoding UTF8
```

Ожидается `LastTaskResult = 0` после успешного завершения опроса. В отчётах:

| Файл | Назначение |
| --- | --- |
| `report.html` | Основной мониторинг раздач |
| `films.html` | Новые публикации из ленты |
| `auto-downloads.html` | Очередь и подтверждения автозагрузки |
| `monitor.log` | Диагностика, ошибки и результаты опросов |

Если запись получила статус «Передано клиенту», дождитесь следующего опроса: TorrentControl должен проверить её хеш и фактический путь. При «Нужна проверка» сначала проверьте запись в µTorrent и только затем используйте **`8-Review-autoload.cmd`**. **Не удаляйте `auto-state.json`**: это журнал защиты от повторного добавления.

## Защита данных и дисков

- Автоматические загрузки сохраняются в `D:\Фильмы\rt-<номер темы>`.
- На D: сохраняется не меньше **20 ГиБ** резерва; свободное место пересчитывается с учётом незавершённых загрузок.

## Если TorrentControl уже установлен

**Не запускайте заново `1-Setup.cmd` и не переписывайте папку программы во время активного опроса.** Перед обновлением нужно проверить исходную версию, наличие `auto-state.json`, текущие credentials RuTracker, сделать полную резервную копию, выполнить проверенный перенос файлов программы и убедиться в успешном запуске монитора. При необходимости выполнить откат.

Подробная проверенная для обновления **1.8 → P0** процедура с блокировкой `monitor.lock`, копированием и откатом пока находится в исходной документации ветки разработки. До переноса этой процедуры в отдельный проверяемый документ **не считайте эту краткую инструкцию готовым руководством по обновлению рабочего ПК**.
