TORRENTCONTROL 1.7

ОБНОВЛЕНИЕ
Замените исходные файлы в C:\TorrentMonitor.
Сохраните config.json, credential.xml, state.json, feed-state.json,
а также autoload.json и auto-state.json, если они уже существуют.
1-Setup.cmd повторно запускать не нужно.

АВТОЗАГРУЗКА
6-Enable-autoload.cmd — включить. Первый запуск исключает текущую подборку.
2-Run-once.cmd — проверить сейчас; далее работает прежнее расписание каждые 15 минут.
7-Disable-autoload.cmd — выключить будущие добавления; текущие раздачи продолжатся.

Только новые темы раздела 252 после включения: WEB-DL/WEB-DLRip/BDRip, Dub/MVO/DVO.
Папка D:\Фильмы\rt-<номер темы>, размер отдельной раздачи не ограничен.
Запас 20 ГиБ плюс место для ещё не скачанных данных текущих заданий на D:.
Максимум одно добавление за опрос; существующие хеши на всех дисках пропускаются.
Лента и метаданные приходят через GitHub. Python/aria2 на Windows не требуются.

report.html — основной отчёт; films.html — подборка;
auto-downloads.html — журнал автозагрузки; monitor.log — ошибки.
После отправки новое задание ожидает подтверждения пути; повторно не отправляется.
При статусе «Нужна проверка» проверьте задание в µTorrent. Не стирайте auto-state.json.

Удаление отключено. D:/F: отслеживаются; E: архив и C: система исключены из отбора.
WebTLO и общие настройки µTorrent не меняются.
Не меняйте проверенную настройку переноса: только из папки по умолчанию.
µTorrent должен быть запущен в одном экземпляре на этом компьютере.
Пользователь Windows должен оставаться вошедшим; блокировка/отключение RDP допустимы.
Полная документация — README.md.
