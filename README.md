## Torrent Control

**Torrent Control** - монитор раздач для Windows и µTorrent с автоматическим добавлением новых фильмов.

>Программа работает локально, формирует HTML/CSV-отчёты, контролирует свободное место и использует **персональные `.torrent`**, для учёта отдачи в профиле RuTracker. Новые раздачи добавляются только после отдельного включения автозагрузки.

## Возможности

- Мониторинг раздач через µTorrent WebUI и локальный `resume.dat`.
- Отчёты `report.html`, `films.html` и `auto-downloads.html`, журнал `monitor.log`.
- Проверка infohash, метаданных, пути и наличия раздачи в клиенте перед добавлением; защита от повторной передачи.
- Получение персонального `.torrent` с RuTracker под учётной записью пользователя, без подмены адреса трекера публичным.
- Запуск по расписанию **каждые 15 минут** через Планировщик Windows.

>Удаление торрентов и файлов в этой версии не реализовано. только отслеживаются; Мониторинг и автозагрузка не меняют глобальные настройки µTorrent и других приложений; отдельный инструмент перепривязки после явного подтверждения изменяет только трекеры выбранных раздач.

## Быстрый старт

1. Скачать архив программы из **GitHub Releases** и распаковать, например, в `C:\TorrentMonitor`, сохранив структуру каталогов.
2. Настроить WebUI в µTorrent и выполнить **`1-Setup.cmd`** - только при **первой установке**.
3. Выполнить **`9-RuTracker-login.cmd`**, затем **`10-RuTracker-check.cmd`**. При проблемах с доступом к сайту использовать **`15-RuTracker-connection.cmd`**.
4. При необходимости включить автозагрузку командой **`6-Enable-autoload.cmd`**.
5. Запустить **`2-Run-once.cmd`** и открыть `report.html`.

Подробности: [Установка](INSTALL.md) · [Интеграция с RuTracker](RUTRACKER.md) · [Изменения](CHANGELOG.md).

> При **обновлении существующей установки** не запускайте `1-Setup.cmd`: это первичная настройка и регистрация задания. Порядок безопасного обновления необходимо отдельно проверить для исходной версии и состояния ПК - см. [INSTALL.md](INSTALL.md).

## Как устроены обновления ленты

Публичную ленту и метаданные получает GitHub Actions. Клиент читает `data/forum-252.json` и `data/metadata/` через `raw.githubusercontent.com`. У GitHub Actions возможны задержки запуска, поэтому новые темы иногда появляются с опозданием. Логины, пароли, cookies и персональные `.torrent` **на GitHub не отправляются**.
